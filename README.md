# 📍 Карта объектов из Битрикс24

Интерактивная карта с объектами из Битрикс24.

## 🌐 Сайт

[https://i-grivev.github.io/map-app/](https://i-grivev.github.io/map-app/)

## 🔄 Автообновление

Данные обновляются каждый день в 6:00 по Москве.

## 🛠️ Технологии

- **Карта**: Яндекс.Карты API
- **Данные**: Битрикс24 REST API
- **Хостинг**: GitHub Pages
- **Автообновление**: GitHub Actions
- **Геокодирование**: Яндекс.Карты + OpenStreetMap

## 🔐 Безопасность

Все ключи хранятся в зашифрованных GitHub Secrets.
